# General Health Query Chatbot - Task 04

## Project Overview

This project was developed as part of my AI/ML Engineering Internship at DevelopersHub Corporation. The main objective of this task was to build a general health query chatbot using an open-source Large Language Model (LLM) and prompt engineering techniques.

The chatbot is designed to answer common health-related questions in a simple, clear, and user-friendly manner while maintaining safety and ethical boundaries. It provides general information and guidance but avoids giving direct medical diagnoses or professional treatment advice.

---

## Objectives

- Build a health query chatbot using an open-source LLM
- Apply prompt engineering techniques
- Create a user-friendly interface
- Ensure safe and responsible responses
- Handle common health-related questions appropriately

---

## Technologies Used

- Python
- Hugging Face API
- Meta-Llama-3-8B-Instruct
- Gradio
- Hugging Face Hub

---

## Project Workflow

### 1. Model Integration
The Meta-Llama-3-8B-Instruct model was integrated using Hugging Face API for generating responses.

### 2. Prompt Engineering
Prompt engineering techniques were used to guide the chatbot behavior and improve response quality.

The chatbot was instructed to:

- Act as a friendly and empathetic assistant
- Provide easy-to-understand responses
- Avoid direct diagnoses
- Avoid unsafe medical recommendations
- Suggest consulting healthcare professionals when necessary

### 3. Safety Implementation

Safety rules were added to ensure responsible use of the chatbot:

- Restrict medical diagnosis generation
- Prevent prescription-related advice
- Handle emergency situations safely
- Add medical disclaimers where required

### 4. User Interface

Gradio was used to build a simple web-based interface that allows users to interact with the chatbot easily.

---

## Example Queries

Examples of questions that can be asked:
